🖥️ DomainLinks Frontend – C# WPF Application

The frontend of the DomainLinks application is built using Windows Presentation Foundation (WPF) with C#. It provides a native Windows desktop experience with rich UI capabilities and seamless AI integration.

✨ Frontend Highlights

  • MVVM Architecture - Clean separation of UI and business logic
  • XAML-Based UI - Declarative layout with modern styling
  • WebView2 Integration - Edge Chromium rendering for rich content
  • AI-Powered Features - Ollama model integration with streaming responses

🔑 Key Features

  • MVVM Pattern - Strong data binding and clean separation of UI and logic
  • XAML-Based UI - Declarative layout and styling
  • .NET Libraries - Integration with networking, file I/O, and threading
  • Responsive Design - Using Grid, StackPanel, and adaptive resources
  • Custom Controls - MaterialDesignInXAML, MahApps.Metro support
  • Event-Driven - Commands and routed events
  • Data Visualization - Charting controls and custom renderers
  • Animations - Transitions for enhanced user experience
  • AI Chat Interface - Integrated Ollama model support with streaming responses
  • Document Management - PDF/Image upload with OCR processing UI
  • WebView2 Integration - Edge Chromium rendering for rich AI output
  • Advanced Export - Direct export to .docx and .html formats

📦 Desktop Installer

The application is packaged as a Windows desktop installer using ClickOnce or MSIX, allowing easy installation and updates via Visual Studio publish profiles.

📂 Key Source Files

  • MainWindow.xaml.cs – Main window and UI logic
  • DomainLinksDesktop/*.cs – View models and services
  • App.config – Application configuration and settings
  • DomainStoreWindow.xaml.cs – Domain store management
  • ChatBackupService.cs – Chat history persistence
  • OcrViewerWindow.xaml.cs – OCR viewer integration

🚀 Development Workflow

  1. Open solution in Visual Studio 2022
  2. Configure connection strings in App.config
  3. Build solution (Ctrl+Shift+B)
  4. Run application (F5)
  5. Test UI components and API integration

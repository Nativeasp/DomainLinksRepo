🚀 DomainLinks Application

A modern desktop application combining C# WPF front-end with a Python back-end for AI-powered domain management and analytics.

✨ Key Highlights

  • Native Windows Performance - Built with C# WPF for optimal desktop experience
  • AI-Powered Intelligence - Integration with Ollama for local LLM inference
  • Scalable Architecture - RESTful APIs with FastAPI backend
  • Enterprise-Ready - SQL Server integration with robust data management

🔧 Tech Stack

Front-End Technologies

  • C# WPF (.NET 6+)
  • WebView2 (Edge Chromium)
  • XAML Declarative UI
  • MVVM Pattern
  • OpenXML SDK Docx Export
  • Material Design / MahApps.Metro

Back-End Technologies

  • FastAPI (Python 3.11+)
  • SQLAlchemy ORM
  • Windows OCR PowerShell Integration
  • Alembic Migrations
  • AsyncIO Patterns

AI & ML Stack

  • Ollama Local LLMs
  • ChromaDB Vector Store
  • LangChain Framework
  • RAG Pipelines Retrieval

Data & Infrastructure

  • SQL Server Enterprise DB
  • REST APIs Communication
  • File Storage Documents & Assets

Installation

  1. Clone the repository
  2. Install Python dependencies: pip install -r requirements.txt
  3. Configure database connection in app.config
  4. Run database migrations with Alembic
  5. Launch the desktop application from Visual Studio
